# 🏥 AI-Based Diabetes Prediction System

A Machine Learning based web application to predict the risk of diabetes using clinical and lifestyle parameters.  
This project includes data preprocessing, model training, evaluation, and a professional web dashboard using Gradio.

---

## 📌 Project Overview

Diabetes is a chronic disease that affects millions of people worldwide.  
Early detection can help in better treatment and prevention.

This project uses Artificial Intelligence and Machine Learning techniques to:

- Analyze patient health data
- Predict diabetes risk
- Provide confidence score
- Display model performance
- Show health reference ranges

---

## 🚀 Features

✅ Data Preprocessing and Scaling  
✅ Multiple ML Models Training  
✅ Best Model Selection  
✅ Real-time Prediction  
✅ Interactive Web
